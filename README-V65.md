# Eagle Vision V65 — Prime49 Visual Refinement

This release preserves the approved Prime49 calculator layout and logic while applying the requested visual refinements.

## Changes

- Added a Prime49-specific Eagle Vision Capital Systems logo for the navy header and footer.
  - EAGLE is now silver/gray.
  - VISION remains Eagle Vision blue.
  - CAPITAL SYSTEMS and the horizontal rules are silver/gray.
- Changed both monthly/annual processing summary cards from pale blue to pale green.
- Changed dynamic monthly and annual Prime49 payout figures to bold Irish green.
- Changed both estimated-cost cards to pale green with bold Irish-green figures.
- Changed the Prime49 payout and estimated-fees-eliminated result pills to a soft green treatment with bright-white typography.
- Changed the combined bottom-line gain pill from bright blue to Irish green with bold white typography.
- No calculator formulas, values, controls, labels, spacing, or interaction logic were changed.
- Updated Prime49 CSS/JS cache-busting references to V65.
